# Privacy

Spice for GitHub does not collect, transmit, sell, or retain browsing data.

The extension runs locally on `github.com` to detect canonical Spice declaration comments in visible file, blame, diff, review, and markdown code views. GitHub page content is inspected ephemerally in browser memory solely to render that visible feature; it is never collected, transmitted, logged, sold, or retained.

Its only permission is `storage`, used to synchronize the display settings you choose. Those settings contain only prefix-folding, theme, and custom-color preferences—never repository content or browsing history. Annotation rendering and conventional Spice View-path mapping use only the path and source already visible in the current GitHub page. The extension does not make hidden network requests, load remote code, use analytics, or alter repository source. The visible Spice logo and test-to-source links are ordinary user-activated links.

GitHub remains responsible for the page and repository data it serves. Chrome may synchronize extension settings according to the user's browser-account configuration.
