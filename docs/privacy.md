# Privacy

Spice for GitHub does not collect, transmit, sell, or retain browsing data.

The extension runs locally on `github.com` to detect canonical Spice declaration comments in visible Go file and diff views. Its only permission is `storage`, used to synchronize the display settings you choose. It does not make hidden network requests, load remote code, use analytics, or alter repository source. The visible Spice logo is an ordinary user-activated link to the canonical Spice GitHub repository.

GitHub remains responsible for the page and repository data it serves. Chrome may synchronize extension settings according to the user's browser-account configuration.
